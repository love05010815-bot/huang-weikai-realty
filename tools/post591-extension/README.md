# 591 刊登助手 Chrome 外掛

後台 `/admin/post591` 按「🚀 上架到 591」→ 自動開 591 刊登頁 → 這個外掛把四連點、每一格、文案、照片填好 →
右下角面板列出還缺什麼 → **你自己按「保存資料，下一步」和「立即支付」**。

## 裝一次就好（約 1 分鐘）

1. Chrome 網址列輸入 `chrome://extensions` → Enter
2. 右上角把 **「開發人員模式」** 打開
3. 左上角按 **「載入未封裝項目」**
4. 選這個資料夾：`D:\Agent-os\booking-system\tools\post591-extension`
5. 看到「591 刊登助手（凱心成家）」出現在清單、開關是開的 → 完成

以後這個資料夾裡的檔案更新了（我改程式），回 `chrome://extensions` 按那張卡片上的 **↻ 重新載入** 就好。

## 它做什麼／不做什麼

- 只在 `user.591.com.tw/post/*`（刊登流程）這幾頁動作，別的網站一律不理。
- 資料只放在網址 `#` 後面（不會送到 591 伺服器）與這個分頁的 sessionStorage，填完就清掉。
- **不按保存、不按付款、不存你的 591 帳密。**
- 照片是從愛屋圖檔主機抓你那一戶的檔案塞進 591 的上傳框；LINE 文字沒有照片網址就跳過，你自己上傳。

## 填不進去怎麼辦

591 的表單偶爾會改版。面板上紅字寫「○○沒選到」就是那一格要你自己點；其他格照樣填好。
整頁都沒反應：先確認外掛開關是開的、然後在後台重按一次「上架到 591」。

## 這個外掛跟 591 條款

591 服務條款禁止爬蟲與自動下載程式。這個外掛**不抓 591 任何資料**，只是替你把自己的物件資料填進表單、
最後仍由你本人按送出 —— 性質上是輸入輔助。但「用程式操作表單」仍可能被 591 視為自動化，
2026-09-01 已向使用者說明過帳號風險，由他本人決定使用。
