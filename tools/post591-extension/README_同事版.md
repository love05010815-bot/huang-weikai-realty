# 591 刊登助手（Chrome 外掛）— 安裝與使用

貼上愛屋型錄（或自己打的物件文字）→ 按「解析」→ 按「上架到 591」，外掛會開一個 591 刊登分頁，
把每一格、文案、照片自動填好。**「保存資料，下一步」和「立即支付」永遠由你自己按。**

文案只用型錄裡的資訊：「☆主推特色介紹:」加上型錄的 ✨ 特色行，**不帶任何人的固定文案**。
想在每戶文案後面固定加一段（自己的電話、LINE、店名）可以在「⚙ 我的資料」填，不填就沒有。

## 安裝（只要做一次，約 2 分鐘）

1. 把這個壓縮檔解壓縮到一個**以後不會搬走、不會刪掉**的資料夾（例如 `D:\591刊登助手\`）。
   ⚠️ 解壓後的資料夾裡要直接看到 `manifest.json`，不要多包一層。
2. Chrome 網址列輸入 `chrome://extensions` → Enter
3. 右上角把 **「開發人員模式」** 打開
4. 左上角按 **「載入未封裝項目」** → 選剛才解壓縮的那個資料夾
5. 清單出現「591 刊登助手」、開關是開的 → 完成
6. 建議把它釘在工具列：網址列右邊的 🧩 拼圖圖示 → 找到「591 刊登助手」→ 按 📌

## 第一次用：貼授權碼、填自己的資料

1. 點工具列上的「591 刊登助手」圖示，會開一個頁面
2. 上方「⚙ 我的資料」最上面那格「**授權碼**」：貼上黃瑋凱 LINE 給你的 `WK-XXXX-XXXX-XXXX`（整組貼、多一個字少一個字都不行），
   再填 **姓名、手機、LINE ID**（姓名會變成 591 的聯絡人），按「儲存」。
   → 頁面上方出現綠色「✅ 授權有效：你的名字，到（日期）為止」才算完成；沒有有效授權碼，「解析」和「上架」都不會動
3. 「固定尾段」是選填：想在每戶文案後面固定接一段（電話、LINE、店名）就填在這裡，
   `{{name}}` `{{phone}}` `{{line}}` 會自動換成你填的；留空就只有型錄的資訊
   ⚠️ 自己寫的文案裡「唯一」「最大」「最快」「保證」這類絕對用語有公平交易法風險，工具會用黃底標出來，留不留自己決定

## 授權碼的規矩

- 這批同事共用一組碼；每台 Chrome 第一次按儲存會登記一台，一組碼能用的電腦數有上限，滿了會顯示「已達上限」——跟黃瑋凱說一聲就好。
  **只給店內同事用，不要轉傳給別人**（他在後台看得到這組碼有幾台電腦在用）。換電腦或重裝 Chrome 會算成新的一台。
- 有效期限寫在黃瑋凱給你的授權訊息裡（第一批統一到 **2026-09-20**，台灣時間當天結束）。到期會顯示「授權已到期」，
  要繼續用請找他延長，**不用重新安裝、不用換檔案**；延長後重新打開外掛頁（或按一次「儲存」）就恢復。
- 外掛打開時（每隔幾小時）和每次按「上架」時會連黃瑋凱的網站（weikaihouse.com）：驗證授權碼、記一次上架，
  只送授權碼、這台 Chrome 的安裝編號、外掛版本、「這次是上架」的標記，**不送物件資料、不送你的姓名電話**。
  他在後台看得到每個人上架過幾次。沒網路時三天內驗證過會先放行。
- 壓縮檔和授權碼都不要轉給別人：碼綁了你的電腦，別人拿去也不能用。

## 樂屋網也能上

同一份資料解析完，按「🏠 上架到樂屋」會開樂屋網的刊登頁（出售或出租自動對應）把每一格、文案、照片填好；
樂屋的「庫存」（先存不上架）和「上架」也都是你自己按。物件名稱樂屋只收 25 字，超過會自動截短。
第一次用要先在 Chrome 登入樂屋會員中心；聯絡人會改成「自行填寫」用你的姓名手機。

## 出租也一樣

貼**租屋型錄**（標題「租-」開頭、有「租金／押金」欄）會自動當出租處理：開 591 出租表單，
租金、押金、電梯、可使用坪數、身份要求、開伙／寵物、租金包含、水電繳法都會填好。
預設：押金 2 個月、最短租期 1 年、身份三種都勾、可開伙、不可養寵物、租金不含（型錄「含管」「禁寵」有寫就照型錄）。
**提供設備／提供家具**要你自己看照片勾；型錄沒竣工日會點「屋齡不詳」，知道的話自己改。

## 每一戶怎麼上

1. 打開愛屋電子型錄，把地址旁的「**顯示**」點開（門牌才會帶進來）→ Ctrl+A → Ctrl+C
2. 點外掛圖示 → 貼到「① 貼上資料」→ 按「解析」
3. 看「③ 每一格」：**紅底**的格子是資料裡沒有的（常見：裝潢程度），補一下；其他格覺得不對也可以直接改
4. 「④ 標題與描述」可以改字；「⑤ 照片」若寫沒抓到：把**型錄頁的網址**（網址列那條）和「**更多照片**」的連結
   （在連結上按右鍵 → 複製連結網址）都貼進去，幾條都可以。型錄頁上顯示的那幾張會由外掛把那一頁抓回來找，
   更多照片的清單直接讀；下面會寫每條各抓到幾張
5. 按「🚀 上架到 591」→ 會跳到 591 分頁自動填。**填的時候不要切到別的分頁**，等右下角面板出現「✅ 填完」
6. 從上往下核對一遍（尤其門牌「樓」、車位型式、裝潢程度、照片張數），再自己按「保存資料，下一步」→「立即支付」

## 常見狀況

- **直接點資料夾裡的 app.html 打開，按鈕都沒反應**：那樣開瀏覽器會擋住程式。這一頁要從 Chrome 工具列的
  「591 刊登助手」圖示打開（先照上面「安裝」做完，再點網址列右邊的 🧩 → 591 刊登助手）。
- **紅字「🔒 …授權…」**：授權碼沒填、打錯、到期、或這組碼的電腦數已達上限，照字面找黃瑋凱處理；「連不上驗證伺服器」先確認網路再試。
- **面板紅字「○○沒選到」**：那一格自己點一下就好，其他格照樣填好。
- **卡住不動**：多半是分頁被切到背景（Chrome 會把背景分頁放慢），點回來等它跑完；或把 591 分頁關掉、回外掛頁再按一次上架。
- **要先登入 591**：外掛不會幫你登入，請先在 Chrome 登入 591 會員中心再按上架。
- **591 改版填不進去**：告訴黃瑋凱，程式要跟著改。改好後會給你新的壓縮檔，解壓縮**覆蓋原資料夾**，
  再到 `chrome://extensions` 按那張卡片的 ↻ 重新載入。

## 它做什麼／不做什麼

- 只在 `user.591.com.tw/post/*`（刊登流程）動作，別的網站一律不理。
- 不抓 591 任何資料、不存你的 591 帳密；除了驗證授權碼會連 weikaihouse.com（見上面「授權碼的規矩」）之外不連任何伺服器；
  你的姓名電話只存在自己的 Chrome 裡。
- 照片是從愛屋圖檔主機抓「你自己那一戶」的檔案塞進 591 的上傳框。
- 591 服務條款禁止爬蟲與自動下載程式；這個外掛只是替你把自己的物件資料填進表單、最後由你本人送出，
  性質上是輸入輔助，但「用程式操作表單」仍可能被 591 視為自動化，是否使用請自行評估。
