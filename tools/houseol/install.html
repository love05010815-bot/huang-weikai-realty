🏠 愛屋抓取小工具

把下面這個藍色按鈕，拖到瀏覽器的書籤列（網址列下面那排）。拖曳的時候滑鼠按著按鈕不放，移到書籤列上再放開。

📥 抓愛屋這一頁

如果拖曳失敗、書籤列沒顯示：
  1. 先按右鍵這顆按鈕 → 「複製連結網址」
  2. 在瀏覽器新增一個書籤（通常是網址列旁邊的星星，或選單裡的「加入書籤」）
  3. 書籤名稱隨便打（例如「抓愛屋」），網址欄位貼上剛剛複製的東西
  4. 存檔

怎麼用

  1. 登入愛屋，切到「委託中」物件列表頁
  2. 按一下書籤列上的「抓愛屋這一頁」
  3. 會跳出提示說抓到幾筆，同時瀏覽器會自動下載一個 houseol-page-xxxx.json 檔案
  4. 翻到下一頁，再按一次書籤，重複到最後一頁（總共約 12 頁）
  5. 抓完之後，去瀏覽器的「下載項目」資料夾，把所有 houseol-page-*.json 檔案交給小凱（傳給他、或告訴他檔案在哪）
放心的部分：這支工具只讀「你登入後看到的畫面文字」，完全不碰帳號密碼，也不會自動幫你翻頁或做任何點擊 —— 每一頁都要你自己按書籤。 地址欄位在抓的當下就只留「梧棲區」這種行政區等級，完整門牌不會出現在下載的檔案裡。
