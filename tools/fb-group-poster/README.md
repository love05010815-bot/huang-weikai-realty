# FB 社團廣告助手（Chrome 外掛）

用你登入的**粉專身分**，把後台寫好的一版廣告，逐一發到你挑選的 Facebook 社團。
搭配後台頁面 `/admin/fb`（社團廣告發佈）使用。

## 為什麼需要外掛

Facebook 在 2024 年 4 月停用了社團發文 API，**沒有官方 API 能把貼文發到社團**。
weikaihouse.com 架在 Vercel 上，伺服器不能開瀏覽器、也無法保持你的 FB 登入去逐一發文。
所以跟你的「591／樂屋刊登助手」一樣：後台只負責「出稿」，真正在 Facebook 按按鈕那段，
由這支外掛在你自己的 Chrome 裡完成。

這種做法**不符合 Meta 服務條款**，帳號或粉專有被限制的可能，請自行評估。

## 安裝

1. Chrome 打開 `chrome://extensions`，右上角開「開發人員模式」。
2. 按「載入未封裝項目」，選這個資料夾 `booking-system\tools\fb-group-poster`。
3. 到後台 `/admin/fb` 按 F5 重新整理，頁面上方會顯示「外掛已安裝」。

## 使用

1. 先到 Facebook 登入，右上角頭像 → 查看所有個人檔案 → 切換成你的**粉專**。
2. 後台 `/admin/fb`：
   - 設定：填**粉專名稱**（要和 FB 上顯示的一樣）、每日上限。
   - 廣告文案：寫一版文字、加圖片、儲存。
   - 社團清單：按「從 FB 抓我加入的社團」自動帶進來再勾（見下一段），或自己貼社團網址
     （粉專要先加入該社團、社團允許粉專發文）。
   - 發佈：選文案、勾社團、按「開始發佈」。
3. 外掛會開一個社團分頁，自動切成粉專身分、填好文案和圖片，然後停下來。
   **你自己核對後按 Facebook 的「發佈」**，再按右下角面板的「✅ 我按過發佈了，下一個社團」，就換下一個。
   面板另有「跳過這個」「停止全部」。

## 抓「我加入的社團」（1.2.0 新增）

社團清單不用自己一個一個貼網址了：後台 `/admin/fb` →「社團清單」→「**從 FB 抓我加入的社團**」。

1. 外掛開一個分頁到 Facebook 的「你的社團」（`facebook.com/groups/joins/`）。
2. 自動往下捲，把你**已經加入**的社團名稱與網址收集起來（捲到沒有新的就停，最多 4 分鐘）。
   這期間讓那個分頁留在前景 —— Chrome 會凍住背景分頁的計時器。
3. 回後台，抓到的清單在「社團清單」頁，**你自己逐一勾**要用哪些，按「加入清單」。
   已經在清單裡的會標「已有」、不能勾，不會重複加。

- 「建議的社團」那一段（FB 推薦你加入的）會自動切掉，只留你已加入的。
- 只讀社團名稱與網址，**不發文、不會加入或退出任何社團**；抓到的清單只存在你的瀏覽器。
- 抓到 0 個：多半是那頁不是「你的社團」清單，或 FB 改版了 —— 面板上有「再抓一次」。

## 檔案

| 檔案 | 作用 |
|---|---|
| `manifest.json` | 外掛設定（MV3） |
| `background.js` | 任務佇列：存廣告、開社團分頁、換下一個、記進度；抓社團清單的狀態 |
| `bridge.js` | 後台 `/admin/fb` ↔ 外掛 的橋（postMessage ↔ 背景程式；回傳進度與抓到的社團） |
| `content.js` | 在社團頁裡填表、右下角操作面板（**不替你按發佈**）；在「你的社團」頁負責往下捲抓清單 |
| `fb-selectors.js` | Facebook 介面文字（中英）＋ 社團連結解析。改版後改這裡 |
| `selftest.html` | `fb-selectors.js` 的自我測試（18 項）。用瀏覽器直接打開這個檔就會跑，標題會顯示 ALL PASS |
| `panel.css` | 面板樣式 |

## 改版壞了怎麼辦

Facebook 常改版。若面板出現「找不到發文框」「發文視窗沒跳出來」，多半是介面文字或結構變了：
先改 `fb-selectors.js` 裡對應的候選字；若是結構變了，調 `content.js` 裡找元素的邏輯。
改完到 `chrome://extensions` 按這張卡片的 ↻ 重新載入，再回社團頁重試。

## 隱私

- 廣告內容與社團清單存在後台頁面的瀏覽器 IndexedDB，以及外掛的 `chrome.storage`（發佈當下），**不會上傳到任何伺服器**。
- 外掛只在 `www.facebook.com/groups/*` 和後台 `/admin/fb` 頁面執行，不碰其他網站，也不讀你的 FB 帳密。
