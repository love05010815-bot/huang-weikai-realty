Chrome 外掛・同事版

FB 社團廣告助手

一版廣告，發到你勾好的每個 Facebook 社團。外掛負責打開社團、填好文案和照片；「發佈」永遠是你自己按。

版本 {{VERSION}}・只要 Google Chrome・約 5 分鐘裝好

STEP 1裝進 Chrome解壓縮、載入未封裝項目、登入 FB STEP 2授權碼與第一次設定貼碼、發文身分、固定尾段、抓社團 STEP 3每一戶怎麼發貼愛屋連結 → 帶入 → 發佈
一句話講完它做什麼 在外掛頁寫好一則廣告、勾好社團、按「開始發佈」，它會一個社團一個社團幫你打開、把文案和照片填好，然後停下來等你按 Facebook 的「發佈」。 你按完，再點右下角面板的「下一個社團」，就換下一個。

① 裝進 Chrome只要做一次。要用 Google Chrome，別的瀏覽器不行。

  1. 把壓縮檔解壓縮到一個「以後不會搬走、不會刪」的資料夾

    例如 D:\FB社團廣告助手\。這個資料夾就是外掛本體，搬走或刪掉外掛就壞了。

    打開資料夾直接看得到 manifest.json，沒有多包一層

  2. 打開 Chrome 的外掛頁

    網址列輸入 chrome://extensions 按 Enter。

  3. 右上角把「開發人員模式」打開

    左上角出現「載入未封裝項目」按鈕

  4. 按左上角「載入未封裝項目」，選剛才那個資料夾

    清單出現「FB 社團廣告助手」，右下角開關是藍色（開的）

  5. 把它釘到工具列（建議）

    網址列右邊的 🧩 拼圖圖示 → 找到「FB 社團廣告助手」→ 按 📌。以後點這個圖示就開工具頁。

  6. 先在 Chrome 登入 Facebook，切成你要發文的粉專身分

    右上角頭像 → 查看所有個人檔案 → 選粉專。外掛不會替你登入、也不會存你的帳密。

② 貼授權碼、第一次設定只要做一次，全部存在你自己的 Chrome 裡。

  1. 點工具列的「FB 社團廣告助手」圖示

    會開一個新分頁，最上面是「授權碼」那格。

  2. 貼上黃瑋凱 LINE 給你的授權碼，按「儲存並驗證」

    長這樣：WK-XXXX-XXXX-XXXX，整組貼、多一個字少一個字都不行。

    綠色「✅ 授權有效：…，到（日期）為止」。沒有這行，發佈、抓社團、帶入都不會動

  3. 「⚙️ 設定」→ 新增發文身分

    名稱要跟 Facebook 上顯示的一模一樣（粉專名稱，或帳號名稱）。發文時外掛會核對：不是這個身分就停下來問你，不會用錯身分發出去。有兩三個粉專就各加一個。

  4. 「⚙️ 設定」→ 固定尾段

    每一則廣告發佈時自動接在文案後面的那一段：你的電話、LINE、店名、想固定講的話。預設是空的，自己填；不填就只有文案本身。

  5. 「👥 社團清單」→「從 FB 抓我加入的社團」

    外掛開一個分頁到 Facebook 的「你的社團」自動往下捲，把你已經加入的社團抓回來。這期間讓那個分頁留在前面，捲完會自己停。回工具頁逐一勾要用的，按「加入清單」。也可以自己貼社團網址。

    「所有社團」表格裡有你勾的那些，「啟用」都是打勾的

一個 Facebook 帳號＝一個 Chrome 使用者 外掛不會、也不能替你切換 Facebook 帳號（那要碰密碼）。同一個帳號底下的幾個粉專可以在發文視窗切； 要用另一個帳號發，請在 Chrome 右上角開另一個「使用者」登入那個帳號，在那個使用者裡再裝一次外掛。

③ 每一戶怎麼發從貼連結到第一個社團填好，大約一分鐘。

  1. 「📝 廣告文案」最上面貼愛屋物件連結或案號，按「帶入」

    案名、開價、路名、格局、登記坪數、主＋附屬、樓別／樓高、屋齡、車位、環境特色會自動填成草稿。型錄上讀不到的欄位會用橘色提示你補，不會亂猜。

    標題和貼文內容都填好了，第一行是【案名】

  2. 按「📷 帶入型錄照片」

    最多 10 張，按下去一張一張進來。不要的按縮圖右上角 ✕；也可以自己「選擇檔案」加圖。

  3. 看一遍、改一改，按「💾 儲存文案」

    帶進來的是草稿，想怎麼改就怎麼改。固定尾段不用貼在這裡，發佈時會自動接上。

  4. 「🚀 發佈」：選文案、選發文身分、勾社團，按「開始發佈」

    右邊預覽顯示的就是會貼出去的全文（文案＋固定尾段），看到什麼就發什麼。

  5. 外掛開第一個社團，填好就停

    它會先核對發文身分、再填文案和照片。填的時候不要切到別的分頁——Chrome 會把背景分頁凍住，看起來像卡住。

    右下角面板寫「內容已填好。請核對後按 Facebook 的『發佈』」

  6. 你自己核對，按 Facebook 的「發佈」，再按面板的「✅ 我按過發佈了，下一個社團」

    就會開下一個社團。不想發這個社團按「跳過這個」，整批停按「停止全部」。到每日上限會自動停。

  7. 回工具頁的「📜 發佈紀錄」看整批結果

    每個社團發了沒、跳過的、失敗的原因都在。

按發佈之前，核對這幾樣外掛填得對不對，最後一關是你的眼睛。

常見狀況

直接點資料夾裡的 app.html 打開，畫面不會動
要從 Chrome 工具列的「FB 社團廣告助手」圖示打開（先照 ① 裝好）。
紅字「🔒 …授權…」
授權碼沒填、打錯、到期、或這組碼的電腦數已達上限，照字面找黃瑋凱處理。「連不上驗證伺服器」先確認網路再按一次「儲存並驗證」。
面板說「找不到發文框」
你（或粉專）還沒加入那個社團、社團不開放發文，或 Facebook 改版了。按「跳過這個」換下一個；很多社團都這樣就告訴黃瑋凱。
面板說「目前的發文身分不是 ○○」
在發文視窗左上角切成正確的身分，再按面板的「我切好了，繼續填」。是另一個 Facebook 帳號的話，要用另一個 Chrome 使用者。
卡住不動
多半是分頁被切到背景。點回那個分頁等它跑完；還是不動就關掉那個分頁、回工具頁按「停止」，再重新「開始發佈」。
「從愛屋帶入」說抓不到
確認貼的是愛屋的物件連結或案號（AA 開頭）；物件已下架也會抓不到。型錄上沒有的欄位本來就不會帶，自己補。
今天的每日上限到了
「⚙️ 設定」裡可以調；預設一天 10 個社團是為了帳號安全，別調太高。
Facebook 改版填不進去
告訴黃瑋凱，程式要跟著改。改好會給你新的壓縮檔：解壓縮覆蓋原資料夾，再到 chrome://extensions 按那張卡片的 ↻ 重新載入。

要知道的規矩

  • 它永遠不替你按「發佈」。發出去的每一則都是你自己按的，發之前看一眼。
  • 授權碼只給店內同事用，不要轉傳。這批同事共用一組碼；每台 Chrome 第一次驗證會登記一台、有台數上限，滿了跟黃瑋凱說一聲。換電腦或重裝 Chrome 算新的一台。
  • 到期不用重裝。期限寫在黃瑋凱給你的授權訊息裡；到期找他延長，延長後按一次「儲存並驗證」就恢復。
  • 你的東西只在你的 Chrome 裡。文案、照片、社團清單、發文身分都存在這台電腦，不上傳。外掛只在驗證授權碼與「從愛屋帶入」時連黃瑋凱的網站（weikaihouse.com），送的是授權碼、這台 Chrome 的安裝編號、外掛版本、你貼的那一戶連結——不送文案、不送社團清單、不送 Facebook 的任何資料。他在後台看得到每組碼發佈過幾次。
  • 外掛只在 www.facebook.com/groups/* 動作，別的網站一律不理，不存你的 Facebook 帳密。
  • 這種做法不符合 Meta 的服務條款。用程式在 Facebook 填表，帳號或粉專有被限制的可能。一天別發太多、內容別重複到像機器，是否使用請自行評估。
