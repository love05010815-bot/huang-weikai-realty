# FB 社團廣告助手（Chrome 外掛）— 安裝與使用

在外掛頁面寫一版廣告（或貼太平洋／愛屋連結自動帶入）、勾好要發的 Facebook 社團，外掛用你登入的**粉專身分**
逐一打開社團、填好文案和照片，**替你按 Facebook 的「發佈」、隔幾秒自動換下一個（預設開）**；想自己按，
到「⚙️ 設定」把「自動按發佈」關掉，它就填好停下來等你（見下面「自動模式」）。

## 安裝（只要做一次，約 2 分鐘）

1. 把這個壓縮檔解壓縮到一個**以後不會搬走、不會刪掉**的資料夾（例如 `D:\FB社團廣告助手\`）。
   ⚠️ 解壓後的資料夾裡要直接看到 `manifest.json`，不要多包一層。
2. Chrome 網址列輸入 `chrome://extensions` → Enter
3. 右上角把 **「開發人員模式」** 打開
4. 左上角按 **「載入未封裝項目」** → 選剛才解壓縮的那個資料夾
5. 清單出現「FB 社團廣告助手」、開關是開的 → 完成
6. 建議把它釘在工具列：網址列右邊的 🧩 拼圖圖示 → 找到「FB 社團廣告助手」→ 按 📌
7. 先在 Chrome 登入 Facebook，並切換成你要發文的**粉專身分**（右上角頭像 → 查看所有個人檔案 → 選粉專）

## 拿到新版本怎麼更新（1.5.4 起：不用覆蓋、不影響電腦綁定）

- 解壓縮到一個**新的**資料夾（例如 `D:\FB社團廣告助手_新版`）→ `chrome://extensions` → 「載入未封裝項目」→ 選新資料夾。
  Chrome 會把原本那張卡片直接換成新版（同一個外掛），授權碼、電腦綁定、設定、社團清單、文案都還在，不用重貼、不用找黃瑋凱。
  載入完可以把舊資料夾刪掉。**不要先按「移除」**：移除會把授權碼和資料一起清掉。
- ⚠️ 從 1.4.x（含）以前的版本升到 1.5.4 的那一次例外：要**先按舊卡片的「移除」**，再載入新資料夾，然後重貼授權碼（還是用你原本那組）、
  重新設定發文身分與固定尾段、再抓一次社團清單。舊版的外掛編號是看資料夾算的，1.5.4 起固定，所以只有這一次會重來，以後更新都不用。
  ⚠️ 編號換了等於這台電腦第一次貼碼，如果顯示「已經綁在另一台電腦上了」，是因為你舊版那組登記還留著——跟黃瑋凱說一聲，
  他在後台把舊的那筆解除綁定，你再貼一次同一組碼就會過，**不用換新的授權碼**。

## 第一次用：貼授權碼、填自己的設定

1. 點工具列上的「FB 社團廣告助手」圖示，會開一個頁面
2. 最上面「**授權碼**」：貼上黃瑋凱 LINE 給你的 `WK-XXXX-XXXX-XXXX`（整組貼、多一個字少一個字都不行），
   按「儲存並驗證」→ 出現綠色「✅ 授權有效：…到（日期）為止」才算完成；沒有有效授權碼，發佈、抓社團、帶入都不會動
3. 「⚙️ 設定」：
   - **發文身分**：新增一個，名稱要跟 Facebook 上顯示的**一模一樣**（粉專名稱或帳號名稱）。
     發文時外掛會核對：不是這個身分就停下來問你，不會用錯身分發出去。
   - **固定尾段**：每一則廣告發佈時自動接在文案後面的那一段（你的電話、LINE、店名…）。預設是空的，自己填；不填就只有文案本身。
   - **每日上限**：一天最多發幾個社團（預設 10）。
4. 「👥 社團清單」→「**從 FB 抓我加入的社團**」：先在「抓回來的社團標給」選這次抓的是哪個身分（兩個以上身分才有這個選單），
   外掛會開一個分頁到 Facebook 的「你的社團」自動往下捲，把已經加入的社團抓回來，你在這裡逐一勾要用的，按「加入／更新」。也可以自己貼社團網址。
   - Facebook 的「你的社團」列的是**你現在用的那個身分**加入的社團，帳號跟粉專不一樣：要抓**粉專**的，先在 Facebook 右上角切換成那個粉專再按抓取；
     要抓**帳號**的，切回個人帳號再抓一次。標好以後，「🚀 發佈」切到哪個身分就只會列它的社團；沒標身分的不會列在任何身分底下（發佈頁會提醒有幾個沒標，可一鍵標給目前身分）。
     同一個社團兩個身分都加入了的，重抓時兩個都會標（預設），切到哪個身分都看得到它；忘了切身分就抓、標錯了，抓取那裡改選「改標給」或「不動它們」再抓一次。
   - 之前抓進來沒標身分的，用表格上面「批次標身分」一次標給某個身分；標錯了用「從 N 個社團拿掉它」清掉再重抓。

## 每一戶怎麼發

1. 「📝 廣告文案」最上面貼**太平洋分享連結／物件頁、S 編號，或愛屋物件連結／案號** → 按「帶入」：案名、開價、路名、格局、坪數、樓別、屋齡、車位、環境特色會自動填成草稿
2. 按「📷 帶入型錄照片」把型錄照片帶進來（最多 10 張，不要的按 ✕ 移掉；也可以自己選檔案）。縮圖可以直接**拖曳**調整順序，發佈時就照這個順序上傳
3. 看一遍、改一改（帶進來的是草稿，型錄上讀不到的欄位會用橘色提示你補），按「💾 儲存文案」
4. 「🚀 發佈」：選文案、選發文身分、勾社團 → 按「開始發佈」
5. 外掛會開一個社團分頁，核對身分、填好文案和照片。分頁**可以切走或縮小**去做別的事（外掛的計時走背景程式，不受 Chrome 放慢背景分頁影響）；
   但別關掉那個分頁、電腦別睡著。
   - **預設（自動模式）**：填好、照片傳完、「發佈」鈕可以按，它就替你按，看到視窗關掉才算發出去，
     再等你設的秒數自動換下一個。見下面「自動模式」。
   - **關掉「自動按發佈」的話（半自動）**：填好就停下來，你自己核對後按 Facebook 的「發佈」，再按右下角面板的「✅ 我按過發佈了，下一個社團」，就換下一個。
     面板另有「跳過這個」「停止全部」。
6. 「📜 發佈紀錄」看整批結果；每個社團的「上次結果」也會記在社團清單裡。

## 自動模式（它替你按「發佈」；預設開）

預設就是開的。「⚙️ 設定」裡「**自動按「發佈」**」那格可以關掉（關了就是半自動：填好停下來等你按）；底下選「每個社團之間怎麼等」：

- **固定秒數**：每個社團發完等固定幾秒（預設 20）再換下一個。
- **自訂範圍、每次隨機**：填「最少～最多」秒（預設 20～60），每個社團之間的秒數都不一樣、比較不像機器；面板會寫這次抽到幾秒。
- 連發太快容易被 Facebook 當垃圾訊息，建議 20 秒以上。每日上限照樣擋。

開了之後，每個社團它會：核對身分 → 填文案、傳照片 → 等「發佈」鈕可以按 → 替你按 → 看到發文視窗關掉才算發出去
（跳出「等待管理員審核」算審核中）→ 面板倒數你設的秒數（可以按「立刻換下一個」或「停止全部」）→ 開下一個社團。
發完整批，到「📜 發佈紀錄」逐一檢查，有問題的社團自己補。那個 Facebook 分頁**可以切走或縮小**去做別的事，每換一個社團也不會再把它搶到最前面；但別關掉它、電腦別睡著。

- **它會停下來等你的情況**（不硬發）：發文身分對不上、文案沒填完整（排版被吃掉）、照片沒傳好、找不到可以按的「發佈」鈕、
  Facebook 說不能發（標成失敗）、按了「發佈」卻 30 秒沒看到視窗關掉（不確定有沒有發出去——你自己看一眼，
  發了就按「我按過發佈了，下一個社團」，沒發就自己按發佈再按那顆）。
- **它會自己跳過的情況**：社團頁面打不開、找不到發文框（多半是還沒加入那個社團）、發文視窗沒跳出來、
  照片沒傳成功（見下一行）、社團跳出「入社審核」要你先回答管理員的問題（外掛不替你答，見「常見狀況」）、
  商品買賣社團的「商品拍賣」表單填不齊（見下面）——面板倒數 5 秒後自動跳過，發佈紀錄寫「…，自動跳過」。
- **商品買賣社團**（1.5.2 起）：這種社團沒有一般的發文框、只有「商品拍賣」鈕。外掛會按它，在「選擇商品類型」選**出售商品**
  （「出售或出租房屋」那張只有出租欄位，賣房不能用），標題用文案第一行、價格從文案的「開價 2988 萬」這種字抓、
  「狀況」自動選（文案寫新成屋／預售選「全新」，其他選「二手 - 良好」）、說明放全文、照片照傳，按「繼續」到「分享到更多地方」
  再替你按「發佈」（Marketplace 那格維持不勾），發佈紀錄標「（商品拍賣）」。
  ⚠️ 商品貼文一律用你**登入的個人帳號**刊登，Facebook 的商品功能沒有粉專身分。
  文案裡沒有價格、沒有照片、或表單還缺它不認得的欄位，就自動跳過，之後自己到那個社團補發。
- **照片**：外掛會等 Facebook 真的收完照片才按「發佈」（縮圖張數跟你帶入的張數一樣，再多等幾秒），
  不是看到縮圖就按。萬一 Facebook 還是跳「抱歉，沒有上傳新的相片」，它會關掉那個訊息、確認照片還在、隔 8 秒再按一次；
  再不行就把這個社團標成失敗換下一個（**不會發出一則沒有照片的廣告**）。之後按「勾選未發佈的」補發就好。

## 中斷後接著發、只發還沒發的

- 「🚀 發佈」第 3 步「勾選社團」右上角有「**勾選未發佈的（N）**」：一鍵勾出啟用中、還沒發成功的社團
  （沒發過、跳過的、失敗的、昨天到每日上限被標「已達每日上限」的都算），再按「▶ 開始發佈」。
- 停止或中斷之後，下面「進度」那一區每一列都可以直接勾，或按某一列的「**從這裡開始**」（這一列和後面全部都勾起來）；
  上面也有「勾還沒發成功的」「全部不勾」。勾好再按「▶ 開始發佈」就接著發。

## 授權碼的規矩

- **一人一組、只能綁一台電腦**（2026-10-05 起發的碼）：你第一次按「儲存並驗證」的那台 Chrome 就綁定了，在別台貼同一組碼會顯示「已經綁在另一台電腦上了」。
  換電腦、重灌 Chrome 算「另一台」——跟黃瑋凱說一聲，他在後台按「解除綁定」，你在新電腦再貼一次就好。
  （1.5.4 起，把新版解到別的資料夾載入**不算**另一台，見上面「拿到新版本怎麼更新」。）
  **不要給別人用**：別人貼了，你自己就不能用（他在後台看得到每組碼綁在哪、發佈幾次）。
- 有效期限寫在黃瑋凱給你的授權訊息裡。到期會顯示「授權已到期」，要繼續用請找他延長，**不用重新安裝、不用換檔案**；
  延長後按一次「儲存並驗證」就恢復。
- 外掛打開時（每隔幾小時）、每次按「開始發佈」、每次「帶入」時會連黃瑋凱的網站（weikaihouse.com）驗證授權碼，
  只送授權碼、這台 Chrome 的安裝編號、外掛版本，**不送你的文案、社團清單、照片、Facebook 資料**。
  他在後台看得到每組碼發佈過幾次。沒網路時三天內驗證過會先放行。

## 常見狀況

- **直接點資料夾裡的 app.html 打開，畫面不會動**：要從 Chrome 工具列的「FB 社團廣告助手」圖示打開（先照上面「安裝」做完）。
- **面板說「找不到發文框」**：你（或粉專）還沒加入那個社團、社團不開放發文，或 Facebook 改版了。自動模式會自己在 5 秒後跳過，關掉自動的話按「跳過這個」換下一個；常常發生就告訴黃瑋凱。
- **發佈紀錄寫「照片沒傳上去」**：Facebook 那邊收照片收失敗（同一組照片短時間連發太多社團比較容易遇到）。這則沒有發出去，
  等一下按「勾選未發佈的」補發；常常發生就把每日上限調低一點、社團之間的間隔拉長一點。
- **發佈紀錄寫「商品拍賣表單沒填齊」**：那是商品買賣社團，外掛按了「商品拍賣」但有東西填不了（最常見是文案裡沒有「開價 N 萬」可以抓成價格，
  或這篇文案沒有照片——商品貼文至少要一張）。紀錄後面會寫缺什麼；要發的話自己到那個社團按「商品拍賣」補，或把文案補好再用「勾選未發佈的」重發。
- **面板說「這個社團跳出『入社審核』」**：那個社團要你先回答管理員的問題才能正式發文，外掛不會替你回答、也不會按「提交」。它會關掉那個視窗、把這個社團標成跳過
  （貼文其實已經在牆上或在等審核的話，會照實記成已發佈／審核中，紀錄後面註明要你去回答）；你自己到那個社團回答問題，之後按「勾選未發佈的」補發。
- **自動模式停下來說「不確定有沒有發出去」**：它按了「發佈」但 30 秒內沒看到視窗關掉。你自己看一眼那個社團：發出去了就按面板的「✅ 我按過發佈了，下一個社團」；沒發就自己按 Facebook 的「發佈」，再按面板那顆。
- **今天的每日上限到了**：剩下的社團會標成「已達每日上限」停下來（「⚙️ 設定」可以調，別調太高）。隔天到「🚀 發佈」按「勾選未發佈的」一鍵勾回來再發。
- **面板說「目前的發文身分不是 ○○」**：外掛不會替你切帳號。在發文視窗左上角切成正確的身分後，按面板的「我切好了，繼續填」；
  如果是另一個 Facebook 帳號，要用另一個 Chrome 使用者登入那個帳號再發。
- **切換發文身分後，出現另一個身分的社團**：那些社團兩個身分都標到了。兩個身分真的都有加入就是正常的；如果其實只有一個身分有加入
  （例如 FB 沒切成粉專就抓），到「👥 社團清單」用「從 N 個社團拿掉它」把標錯的那個身分拿掉，再在 Facebook 切好身分、抓取那裡選「改標給」重抓一次。
- **切換發文身分後清單是空的、說有 N 個沒標身分**：按那一行的「全部標給「○○」」一鍵標過去；只有一部分是它的，到「👥 社團清單」逐一勾「哪個身分」。
- **卡住不動**：多半是分頁被切到背景，點回來等它跑完；或關掉那個分頁、回外掛頁按一次「停止」再重新開始。
- **要先登入 Facebook**：外掛不會幫你登入，也不會存你的帳密。
- **紅字「🔒 …授權…」**：授權碼沒填、打錯、到期、或「已經綁在另一台電腦上了」，照字面找黃瑋凱處理（換電腦要他先解除綁定）；「連不上驗證伺服器」先確認網路。
- **Facebook 改版填不進去**：告訴黃瑋凱，程式要跟著改。改好後會給你新的壓縮檔，照上面「拿到新版本怎麼更新」做：
  解到新資料夾、「載入未封裝項目」，不用移除、不用覆蓋。

## 它做什麼／不做什麼

- 只在 `www.facebook.com/groups/*` 動作，別的網站一律不理。**會替你按「發佈」（預設開，「⚙️ 設定」可以關）**，
  但身分不對、文案沒填完整、照片沒傳好、Facebook 拒絕都會停下來等你。不管哪種模式，發出去的每一則都算你發的，發完要自己檢查。
- 你的文案、照片、社團清單、發文身分只存在你自己的 Chrome 裡，不上傳到任何伺服器（除了驗證授權碼與「帶入」會連 weikaihouse.com，見上面「授權碼的規矩」）。
- 「帶入」讀的是太平洋或愛屋的公開物件資料，只讀你貼的那一戶。
- 這種「用程式在 Facebook 填表」的做法**不符合 Meta 的服務條款**，帳號或粉專有被限制的可能，請自行評估、一天不要發太多。
